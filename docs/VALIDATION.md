- 使用新 Skill 独立生成第二个主题的完整课程。
- 各操作系统、不同 Obsidian/Jupyter 版本的端到端兼容性。
- 未来生成的面板在多设备同步环境中的冲突处理。

原始项目曾对其专用课程和面板做过运行检查，但这些结果不能直接作为新生成课程的验证结论。每个新项目应分别检查自己的输入、依赖、结果、链接和实际界面。
